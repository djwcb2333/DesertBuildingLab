# 版本更新记录

## 0.4.9-ui.1 · 2026-10-09

本次公开更新累积收录0.4.8结构与点缀功能。0.4.8检查是历史证据，不冒充本轮重跑。实际编译环境仍为UE5.8.2／Win64。

### 新增与调整

- 顶栏集中新建、载入、保存更新、另存变体、场景操作、撤销／重做与未保存标记。
- 左栏结构／装饰分类与组合预览，中央放置／选择／删除、高度与相机，右栏固定规则、上下文参数和折叠美术槽，底部统一反馈。
- 四角支柱开关可见、关闭有提示与恢复入口；新建默认开，载入保留原值。关闭前试算现有房间、附件、门窗依赖，拒绝静默失效。
- 选择自动识别已有对象；附件与点缀可原位换方案／方向，非法修改保留原件。回放置清选择，只改下一次默认。
- 当前草稿连续编辑撤销不跨素材与场景操作；恢复参数与小预览，原导航和Shift＋点击／Delete保留。

实际Editor编译成功、源码同步；真实Slate API **168/168**。两张原生Slate截图不是物理鼠标验收。保存再载入不等于磁盘卸载／重启持久性。见[发布说明](ReleaseNotes_0.4.9-ui.1.md)与[验证摘要](Verification_0.4.9-ui.1.json)。

## 0.4.8-stairs.1 · 累积功能与历史检查

- 新放楼梯连接相邻表面。点上方目标Z=k，高层接Z=k−1 → Z=k；实际跑道、平台和入口前80 cm必须有本栋同高连续屋顶，首层仍查地面，不补悬空平台。
- 独立屋顶点缀输入，六种配方复用木板与罐组，不占建筑格；同格替换，结构和通路占用时让位、保留配置。
- 有效上层外门补真实可碰撞门槛，顶面与本层地板同高、厚度向下；有露台时处理开口、墙厚桥接和点缀避让。
- 旧楼梯`GroundLegacy=0`不自动迁移；旧点缀数组为空，不凭空生成手工装饰。
- 连续墙、重复做旧与Houdini **仅评估，未实施**，未新增连续墙生成器或HDA集成。

历史原生检查：楼梯 **250/250**、门槛 **491/491**、点缀 **128/128**，合计 **869**。涉及原生碰撞、保存和关联实例，不代表鼠标、角色、导航、新项目、打包或美术接受。本轮未声明重跑。
